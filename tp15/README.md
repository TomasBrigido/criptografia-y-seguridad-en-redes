# TP15 · Análisis de una infraestructura real

Esqueleto de informe sobre la infraestructura de una radio cooperativa. Incluye contexto documental, análisis de red, nodos y aplicaciones, autodiagnóstico INCIBE y propuesta de mejoras priorizadas.

Completar los campos `\pendiente{...}` con respuestas breves. Diferenciar hechos documentados, supuestos y comprobaciones pendientes; las versiones del documento de 2023 no acreditan el estado actual. No se ha realizado el cuestionario ni una auditoría técnica.

Desde `tp15`:

```bash
latexmk informe.tex
```

Para recompilar al guardar:

```bash
latexmk -pvc informe.tex
```

El borrador se genera en `build/informe.pdf`. Las imágenes adicionales pueden guardarse en `img/`. Se conserva todo el material original. La conclusión y las referencias tienen páginas independientes.
