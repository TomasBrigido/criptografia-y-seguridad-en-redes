# TP11 · Seguridad en sistemas embebidos

Estructura inicial: problemas de seguridad, tres casos de incidentes y práctica de hash, cifrado simétrico y firma digital. Completar los bloques `\pendiente{...}` y guardar las capturas en `img/`.

Desde `tp11`:

```bash
latexmk informe.tex
```

Para actualizar al guardar:

```bash
latexmk -pvc informe.tex
```

El PDF queda en `build/informe.pdf`. Se utiliza el estilo compartido y la configuración de LuaLaTeX de los trabajos anteriores.
