# TP13 · Firma de firmware y Secure Boot v2

Esqueleto basado en `firmadebinarios.md`: marco teórico, implementación con Espressif y SignServer, evidencias, problemas encontrados, siete preguntas de validación y reflexión final.

Completar los bloques `\pendiente{...}` con los resultados de la práctica. Las capturas van en `img/`, con los nombres indicados en `informe.tex`. No incluir claves privadas en las evidencias. El repositorio de código que propone la consigna es opcional.

Desde `tp13`:

```bash
latexmk informe.tex
```

Para actualizar al guardar:

```bash
latexmk -pvc informe.tex
```

El PDF se genera en `build/informe.pdf`. Se utiliza el estilo de `assets/` y la configuración de LuaLaTeX de los trabajos anteriores. La consigna original se conserva sin modificaciones.
