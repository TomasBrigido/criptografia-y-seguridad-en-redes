# TP12 · Cifrado con OpenSSL

Estructura basada en la consigna: cifrado simétrico, asimétrico e híbrido de archivos grandes. Completar los bloques pendientes y guardar las capturas en `img/` con los nombres indicados en `informe.tex`.

Desde `tp12`:

```bash
latexmk informe.tex
```

Para actualizar al guardar:

```bash
latexmk -pvc informe.tex
```

El PDF se genera en `build/informe.pdf`, usando el estilo y la configuración de los trabajos anteriores. Los comandos y resultados se completarán durante la práctica según la versión de OpenSSL utilizada.
